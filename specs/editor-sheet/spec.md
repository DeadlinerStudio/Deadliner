# 普通添加与编辑 Sheet

## 背景
完整任务/习惯表单由 AddDDLActivity 同时持有界面、草稿、权限与保存逻辑，普通添加、编辑及快速添加展开都会开启独立页面。

## 目标
- 普通添加、任务/习惯编辑、快速添加展开、捕获内容和分享导入均在当前页面的柔光玻璃 Sheet 展示完整编辑器。
- 复用现有任务/习惯领域编辑器、AI、日历、分类及日期时间能力；保存后刷新数据并关闭 Sheet。
- 表单页面透明，卡片、分类容器与输入框使用主题色 72% 不透明度背景；保留顶部内容消隐；任务/习惯 Tab 固定于顶栏，Sheet Action 使用普通图标按钮，不再采样玻璃。
- 保留草稿的配置/进程状态恢复，保存期间避免重复提交与误关闭。

## 非目标
不改变快速添加本体的交互、不修改 KMP 数据模型、不迁移详情页、不删除外部快捷方式依赖的 Activity 标识。

## 用户场景
1. 关闭快速添加设置后点击添加，在当前页面打开完整表单 Sheet。
2. 在任务或习惯列表选择编辑，在当前页面打开预填 Sheet，保存后列表刷新。
3. 快速添加展开保留日期、分类、日历事件、备注等已识别字段。
4. 捕获转任务/习惯、分享导入、磁贴和快捷方式进入相同表单；旧 Activity 仅转发兼容入口，不再承载表单界面。

## 验收标准
- 应用内普通添加/编辑不再 startActivity 或 launcher.launch AddDDLActivity。
- 快速添加开关、任务与习惯类型和预填字段正确，编辑时锁定原类型。
- 空名称校验、保存错误、AI 状态、日历授权返回、分类/时间选择保持工作。
- Sheet 页面背景透明，内部容器有一致的主题半透明颜色，保存操作可达且不受 IME 遮挡。
- 本机编译及有意义的路由/草稿测试通过；不连接主力机。

## 风险与约束
- 外部 AddDDLActivity intent 工厂与 extras 向后兼容，因此不进行破坏性 API/数据库变更；不提交工作区中无关改动。
- 编辑态使用右上角勾选 Action 保存，不显示底部保存区或为其分配内容采样；添加态保留底部保存/保存到日历操作。
- 保存回调必须在成功后只发一次；编辑器关闭后取消未完成的 UI 工作，不能因重复收集写入重复日历事件。
- 权限与日期选择使用当前页面 Activity/Compose host，不创建第二个 Activity。
- 禁止操作主力机；设备视觉验收由用户确认。

## 快速添加与完整编辑衔接
快速添加卡片右上角始终显示展开完整编辑器按钮（保存中禁用，识别中允许切换并在目标继续识别）。展开保留原输入、任务/习惯类型、识别草案、手动时间、分类、备注与日历来源。完整编辑器顶部复用快速添加卡片及规则/端侧模型/AI 识别，不再使用独立 generateMixed 链路；确认草案仅填入下方表单，保存仍由编辑器统一完成。

复用卡片嵌入 LazyColumn 时不创建内层纵向滚动或自动抢焦点；原表单的收藏与编辑实体身份保留。配置恢复保留草案，不自动重复保存。

本轮 Kotlin 编译与 38 个相关主机测试通过；新增任务/习惯草稿往返、识别中展开后旧请求取消和续接、空卡片展开、手动修正不被模型覆盖及 AI 类型切换回归。未操作设备，卡片展开与键盘观感待复核。

## FULL 高度、来源展开与自动填表
SheetHeight.MEDIUM 保留原 600dp 内容高度；新增 FULL，面板顶部距状态栏/刘海/窗口标题栏安全区域 8dp，底部覆盖至窗口底部，添加与编辑任务/习惯统一使用 FULL。默认其他 Sheet 不改变高度；小窗口与 IME 约束继续由已有布局处理。

快速添加记录实际卡片屏幕边界，展开时从该边界扩展为 FULL Sheet，420ms 缓动；文本不非等比缩放，表单延后淡入并轻微上浮。来源卡片不再缩回 FAB，同时避免两个入场动画叠加。普通打开/关闭保留现有 Sheet 动画。

完整编辑器顶部仅保留输入、简短识别状态和需要 AI 时出现的生成按钮；删除确认填表、草案预览、属性标签、分类和日历导入入口。规则/端侧/AI 得到有效草案后自动同步识别字段；未识别成功、空输入、过期结果均不覆盖表单。识别未指定的时间、分类、日历来源、收藏等手工字段保留；相同结果不重复写回，手动修改不会被无关重组覆盖。

本轮 Kotlin 编译与全部 409 个本地主机测试通过（108 套件，零失败/错误）。新增真实 Compose 布局验证：FULL 顶部距系统安全区 8dp、MEDIUM 保留 600dp 内容高度、来源展开后可正常关闭，以及精简卡片仅按需出现 AI。自动填表用识别字段合并，任务/习惯分别保留应用签名，并在配置恢复时保存，防止重组和类型切换覆盖手工更改。

展开图标依最新要求缩小 50%（24dp → 12dp），点击区域仍为 44dp。未操作物理设备，跨层玻璃、IME 联动与真实帧率观感待实机复核。

## 顶部间距收紧
添加/编辑表单将 header 后的 24dp 渐隐预留与额外 8dp 合计 32dp，收紧为 12dp 渐隐预留，不再额外加 8dp。其他 Sheet 的 24dp 默认不变，快速添加及无快速添加时首项都不进入静止遮罩区域。

## Action 按压反馈
Sheet 顶栏使用普通 Action 按钮，每个按钮自行提供 MIUIX Sink + 同形状半透明反馈；不能标记为已有外层反馈而跳过。禁用、取消和点击保持原行为。
