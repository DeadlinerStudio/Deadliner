# 总览看板最终视觉参考 · Android v1.0

定版：2026-10-13。以 spec.md 的产品合同及 android-reference-trd.md 的业务/安全区合同为准。原型为示例，原生效果以各端主题与组件实现为准。

## 根页

从上到下：原生可折叠月份顶栏 → 月度活动 → 专注管理/归档双卡 → 任务统计 → 趋势 → 月度复盘。页面横向16dp，各卡间距16dp，复用项目卡片圆角与 surfaceContainer。

| 元素 | Android 定版参考 |
| --- | --- |
| 顶栏 | 大标题“M月总览”，subtitle 年份/月份状态传入原生 MIUIX；月按钮48dp无玻璃点击区、4dp间隔、Material Symbols 左右箭头 |
| 月历 | 内边距16dp，日期格高32dp，格间4dp，周一开始；完成热力与专注小点；完整月不裁周 |
| 双卡 | 各16dp内边距；titleMedium标题/titleLarge数值；仅标题+数据，无灰色说明、无图；宽度不足280dp或字体倍率>1.8时堆叠 |
| 任务统计 | 16dp内边距、8dp内容间距；titleMedium标题、titleLarge完成数；数字下同期变化；右侧88dp实心状态饼图；下面两列状态计数图例 |
| 趋势 | 16dp内边距；titleMedium“趋势”+范围说明；任务/专注两列等宽、间距20dp，各72dp图高；短柱图与细线浅填充，无“任务与专注”大字 |
| 月度复盘 | 同卡片边距/标题；月份、完整bodyMedium正文、可换行关键词胶囊及详情说明；无“AI月度洞察”大字、无省略号/行数限制 |

任务状态使用橙/绿/红/灰语义色，按已有色彩偏好与主题调色；图例同时给文字和计数。同期变化增长绿、下降红、持平中性。任务趋势绿色、专注蓝色；空图为中性基线，空饼图中性圆。图表只预览，完整坐标与交互在趋势详情。

## 二级页与交互

任务统计只保留今日概览/完成时间段/状态统计。趋势使用既有年度、每日、每月、每周图表和设置。月复盘保留 AI/指标/活动/分享。专注管理展示全量记录及更正、确认删除；归档沿用既有界面。所有页面不再使用综合统计 Tab。

二级页以设置页的标准 Scaffold 为基准。顶栏收起时内容上边距随实测高度变化，subtitle由顶栏布局。背景为实体surface并延伸到导航区域，安全区只用于滚动内容底部；保留主宿主已有浮动导航/独立添加按钮与全局专注栏避让。

## 跨端参考

iOS/鸿蒙保持相同层级、路由、数据与操作规则；采用各端既有字体、卡片、原生标题折叠、安全区与分享，不移植 Android 专属玻璃/Canvas/inset API。原型展示展开布局，不能代替实机顶部折叠、字体和手势区验收。示例日期固定2026-10-12，所有数字和 AI 文案均为示例。
