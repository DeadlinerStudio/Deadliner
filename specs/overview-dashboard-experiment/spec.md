# 总览看板 PRD · 最终定版 v1.0

定版日期：2026-10-13。状态：产品方案冻结；Android 实验版本已实现，iOS/鸿蒙待开发。
本文为唯一现行产品合同；实现细节见 android-reference-trd.md，视觉参数见 ui-design.md，交互见 prototype.html。history/ 中旧方案不作为开发依据。

## 背景

原综合统计页混合任务、趋势、月报与专注，信息层级重复。将根页改为月度看板，原三个统计 Tab 拆为独立页面，专注与归档作为靠上的管理入口。保留原有分析、导出和管理功能。

## 目标

用户进入总览即可查看本月活动、任务状态和近期趋势，直接阅读最近结束月份的完整 AI 洞察；点击卡片进入独立详情或管理。三端共享入口、统计口径、月份规则与业务操作，各端使用自身既有导航、主题和安全区组件。

## 非目标

不新增主导航槽位，不修改任务状态、计时、习惯计量、数据库和同步协议，不引入习惯总览功能。习惯总览可沿用未来独立卡片/详情模式，不预留空卡片。不在本轮开发 iOS/鸿蒙或运行模拟器。

## 用户场景与页面结构

| 位置/页面 | 内容 | 点击后行为 |
| --- | --- | --- |
| 总览顶栏 | “M月总览”；原生 subtitle 显示年份及本月进行中/历史月说明；无玻璃的前后月 Material Symbols 按钮 | 切换月历与任务统计，不能进入未来月 |
| 月度活动 | 周一开始的完整月历；热力表示完成任务数量，小点表示有已保存专注 | 日期弹出当天任务完成数和专注时长摘要；未来日期不可点 |
| 专注管理/归档双卡 | 只显示标题和数据；专注为今天已保存时长，归档为当前任务+习惯归档数 | 分别进入专注管理和既有归档页；不跟随月份切换 |
| 任务统计卡 | 所选月完成数“n 项”、较上月同期变化、四色状态饼图及状态计数图例 | 进入任务统计；去掉灰色口径描述、截止日小字和重复趋势图 |
| 趋势卡 | 标题“趋势”、范围说明；两列最近7天任务短柱图/专注细线与浅填充 | 进入全部趋势；不显示“任务与专注”大字 |
| 月度复盘卡 | 标题、最近结束月份、完整 AI 正文和全部关键词、详情/分享入口说明 | 进入该月复盘；无重复“AI 月度洞察”大字，无行数截断 |
| 任务统计详情 | 今日概览、任务完成时间段统计、任务状态统计 | 保留现有任务模块；无 Tab、专注或额外月度图表 |
| 趋势详情 | 年度任务贡献；最近7天任务/专注；最近6个月任务/专注；最近4周任务/专注 | 保留图表细节与现有逾期系列设置；各图使用自身范围 |
| 月度复盘详情 | 月份、口径说明、完整 AI 洞察、月度指标、活动分布、分享 | 保留文字色调、背景图、预览、保存到图库和系统分享 |
| 专注管理详情 | 今天、累计时长/次数；任务/习惯拆分；全部目标及分类分配；全部已保存记录 | 更正时长、确认删除，修改后根页及管理统计刷新 |
| 归档详情 | 既有任务/习惯归档与操作 | 恢复、单项/当前类型批量删除，保留既有确认 |

返回总览保留所选月份和当前页面的滚动位置。管理、趋势及复盘不随所选月份改变，避免将当前管理信息误读为历史月份数据。

## 数据与月份合同

所有日期按设备当前本地时区，月区间为当月1日到下月1日，右端不含；过滤已删除记录。默认本月，历史月份可选，未来不可选。日历按实际完成日期统计任务；专注按开始日期计入已保存记录，正在计时的未保存时长不计入。

任务卡四种状态互斥：完成按所选月完成日期，待办/逾期/放弃按所选月截止日期。未完成且未放弃的记录，截止时刻早于当前时刻为逾期，否则待办。归档已完成计入完成，归档放弃计入放弃。颜色固定语义：待办橙、完成绿、逾期红、放弃灰，可随主题调整色调。历史月显示当前记录的状态，不承诺还原当时状态。

同期比较只针对完成数量。本月1日至今天，对比上月1日至同一日；历史月截止日为所选月末，较短的上月截到其月末。例如10月13日比较10月1–13日与9月1–13日，不与9月全月比较，也不按同一时分秒截断。百分比为差额/前期数量，增加绿、减少红、持平中性；前期为零显示新增项数，不显示无穷百分比。

趋势是以今天为锚点的既有每日/周/月/年度范围，根页两图是最近7天预览；切换月历不改其锚点。双图各自按数据范围缩放，不通过柱高比较任务数量与专注分钟。归档显示当前存量，专注管理汇总全部未删除的保存记录。

## 月度复盘与 AI

复盘入口固定为当前月份的上一个月，不跟随选择器。例如当前为2026年10月，无论查看8/9/10月，总览及复盘详情都展示2026年9月。当前月未结束不生成复盘；跨月自动切换到新的最近结束月份。

AI 正文和关键词按 yyyy-MM 本地持久化。成功结果固化，同一月份不因滚动、切月、进入详情、数据变动或重启自动重新分析。根页与详情并发请求合并；退出卡片不取消已开始的生成。失败持久化尝试状态，只有用户显式重试才能再生成；成功结果不通过重试覆盖。未配置 AI 或失败展示真实不可用状态，不编造洞察。

持久化对象是 AI 结果和尝试记录，不是整月数据库快照；指标和活动分布仍由当前数据库计算。v1 不新增跨端缓存同步协议，每端按同一规则持久化。已有更早月份缓存保留，但 v1 不新增历史复盘列表入口。

复盘指标沿用既有截止日期月份口径，活动分布按完成日期。因此不要求月报已完成数等于日历任务数。月报“逾期任务”沿用现有未完成计数（含放弃），不等同于状态饼图红色项；各端按 TRD 复用共享投影，不另推导。

## 管理交互

专注管理全量记录可达，不截断最近几条。记录展示目标、开始时间、时长及相关习惯日期。更正只允许调低，范围1秒至当前时长、起止墙上时长、Core上限三者最小值。删除复用软删除及同步，不等同撤销习惯打卡。失败保留输入/确认并提示，成功刷新今天、累计、分配和列表。

## 验收标准

- 总览顺序与上表一致；普通手机双卡并排，极窄/大字体可堆叠；没有空的习惯模块。
- 月切换、日期摘要、默认本月和未来禁用正确；主导航与全局专注栏不遮挡末项。
- 任务状态与完成数满足互斥口径；零数据饼图为中性色，不生成假比例；同期边界、短月份、零基数和跨年正确。
- 趋势卡只有标题/范围说明/两张图，图高72dp的 Android 参考成立；完整趋势可独立进入。
- 月复盘全文不省略，重复标题删除；选择月不改变复盘；AI 成功按月保存，失败不自动循环生成。
- 三个旧 Tab 均拆开，原任务模块、趋势设置、月报导出以及专注/归档管理可达。
- 顶栏 subtitle 随原生标题折叠；收起后没有固定残留空白；页面背景延伸到导航区，内容安全距离位于滚动容器内部。
- 各端检查亮/暗主题、字体放大、空/加载/失败/重试、修改返回后的刷新与跨午夜/时区变化。

## 风险与约束

原型使用固定示例日期2026-10-12及示例数字/AI，供层级与交互参考，不用于校验业务计数或像素一致性。Android 构建通过不能代替实机折叠/沉浸视觉验收；用户明确不运行模拟器。冻结的是产品合同，三端复用各端既有 UI 风格，不复制 Android 的渲染或玻璃代码。后续改变统计或管理规则须同步更新 PRD/TRD/原型。
