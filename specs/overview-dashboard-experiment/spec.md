# Android 总览实验版

## 背景
产品依据：/Users/aritxonly/Codes/ProjectDeadliner/Features/PRD/overview-dashboard/spec.md。该目录为产品来源，本目录只记录 Android 实施差异。

## 目标
原总览槽位替换为轻量总览；完整统计下沉且保留三个页签；归档复用现有 Task/Habit 管理能力。

## 非目标
不修改专注领域、数据库、同步或其他端。不把计时页当作专注管理。

## 用户场景
查看近期成果后进入完整统计，或直接打开归档；无数据时管理入口仍显示。

## 验收标准
根页无页签，只有两项指标、最近七天两种量纲趋势和三个目的地操作。返回保持滚动位置，沿用软玻璃宿主和底部安全区。统计加载/错误与管理入口分离，失败可重试。

## 风险与约束
实验版期间统一为最近 7 天：使用 KMP weekly 最后一个滚动窗口和 focus recentDaysSummary。共享层尚无本周任务汇总，不在 Android 重新聚合。专注管理尚无真实路由，入口明确提示未接入；这是一项未完成依赖，不能宣称完整 PRD 交付。保留工作区已有修改，不改专注功能文件。
