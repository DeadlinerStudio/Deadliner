# 柔光玻璃 Dropdown

## 背景
设置选择器使用 MIUIX 0.9.4-rc01 WindowDropdownPreference；其 ListPopupContent 固定 16dp 圆角、不开放连续跟手高亮与玻璃背景插槽。

## 目标
应用侧组件保留 MIUIX BasicComponent 设置行，提供 24dp 圆角独立窗口弹层、同心圆角按压反馈，以及设置窗口完整 Compose 内容的共享柔光采样。

## 非目标
不修改依赖、不启用官方玻璃实验、不迁移其他弹窗、不操作物理设备。

## 用户场景
点开设置选择器，点击选项确认并关闭；长列表使用常规滚动；键盘和无障碍可直接选择。

## 验收标准
按压反馈与持久选中值分离，拖动滚动不改变选项，点击有效选项时仅提交一次；外框 24dp、内框按 8dp 留白使用 16dp 同心圆角；采样包含完整设置页与顶栏，弹层不进入采样源；高级材质关闭时保留不透明语义色回退；支持安全区、RTL、大字与长列表。

## 风险与约束
跨窗口采样需对齐坐标，不能把正在采样的弹层录入其自身背景；无设备验证时需明确观感与跨窗口 GPU 行为待验证。MIUIX API 对照缓存的 0.9.4-rc01 sources.jar 与提交 4a6b750b 文档/示例。

## 实现与验证
设置页全部 SettingsDropdownItem 统一接入应用侧 SoftGlassDropdownPreference。保留 MIUIX BasicComponent 行、DropdownDefaults 颜色与字号、DropdownArrowEndAction、原选项状态和业务回调；弹层使用独立 Dialog 窗口，复用 MIUIX 弹层淡入淡出/弹簧参数，以及 Deadliner 的 dialog 玻璃配方与微调。

WindowGlassBackdropHost 录制完整设置 Compose 窗口，含顶栏与浮层（不含另一个 Dialog 窗口的 Dropdown）；WindowGlassBackdrop 按屏幕原点转换坐标，避免 LayerBackdrop 跨 Owner 时回退为不同窗口局部坐标。通用玻璃 modifier 将输入类型由 LayerBackdrop 放宽到既有 Backdrop 接口，光学处理顺序和配方不变。高级材质或模糊关闭、缺少窗口宿主时使用不透明 surfaceContainer。

手指移动只改变预览胶囊，释放有效行才确认；长菜单靠近可见边缘自动滚动，释放于滚动可见区域外不提交。持久选择保留勾选与 RadioButton 语义，鼠标悬停和键盘焦点也驱动胶囊；弹层有 paneTitle，默认焦点在选中行。

本地编译与 34 个相关主机测试通过。未进行设备/模拟器视觉验证，因此玻璃 GPU 跨窗口采样、连续拖动、焦点恢复、浅深主题与大字观感仍需运行时验收。未执行 ADB、APK 安装、设备截图或 connected 测试。

## 系统截图对照修订
用户提供三张截图：应用版缺少来源让位与面板层级；系统版本隐藏右侧当前值，面板覆盖该来源区域，MIUIX 版本保留来源并压暗页面。按用户要求采用系统路径，保留滑动预览。圆角按用户最新要求由 32dp 调为 24dp。

设置行只隐藏右侧当前值与箭头，保持布局占位；以这一区域作为冻结的来源几何，面板覆盖来源位置、由来源边界展开并反向收回，退出完成后恢复来源。加入独立面板投影并提高玻璃底的遮蔽度，保留采样和主题回退，不采用全屏重压暗。

本轮实现：来源值与选项内容使用交叉淡入淡出，来源副本在来源矩形内保持自然文字比例，选项内容只做等比缩放；容器边界从右侧值的实际矩形展开至最终面板，320ms 进入、220ms 退出，支持中途反向。最终圆角 24dp、面板阴影及提高遮蔽度的玻璃底一起建立层级。最新本地编译和 38 个相关主机测试通过；截图能支持原版问题定位，修改后实际动画及玻璃观感仍待设备验证。

## 玻璃裁剪细带修复
用户截图反馈弹层仅呈现细带。实际 Compose 主机布局测试中面板有完整高度，选项能被布局；代码复核发现上一版将来源到面板的动态 Outline 同时传入外层裁剪与 MIUIX DrawBackdrop 的内部 placeWithLayer 裁剪。上游内部使用稳定 ShapeProvider.shape 包装器，形状更新不强制重测/重新放置，有保留初始来源区域裁剪的风险。

修复：柔光玻璃效果只接受稳定完整的 RoundedCornerShape(24dp)，展开/收回的动态形状仅归外层 clip 和投影管理；不把来源偏移/细小边界送入玻璃内部离屏层。实色回退同样使用完整材质形状。

新增 Robolectric Compose 布局测试，覆盖完整选项高度、玻璃开关路径、真实触摸选择后弹层关闭与来源值恢复；这些主机测试不等同于设备 HWUI/RuntimeShader 像素验收。为支持主机 Compose 测试，复用项目已有 Compose UI Test、AndroidX JUnit 与 Espresso 依赖版本。

修复后本地 Kotlin 编译、41 个相关主机测试及完整 378 个主机测试通过（101 个套件，零失败/错误）。规格校验、git diff --check 与修改文件有效行检查通过。未执行物理设备操作，实机像素效果待复核。

## 官方悬停语义与收起重影修订
依据用户提供的 Screenrecorder-2026-10-16-09-54-56-35.mp4 逐帧复核：收起过程中菜单文字尚未完全退出，来源文字副本已进入，存在两套文字共同可见的区间。修复为以 25% 展开进度作为唯一文字交接点；菜单文字与来源副本的透明度在任意进度乘积均为零，反向收起也不重叠。

悬停框改为外框 24dp 减去 8dp 留白所得 16dp 同心圆角，不随行高变成胶囊。背景透明度由 0.10 降至 0.06，静止选中项仅保留主色文字和勾选，不以背景表示选择。手指、鼠标悬停或键盘真实焦点才绘制交互背景；自动设置初始焦点不在触摸模式生成悬停背景。

手势按 touchSlop 区分点击和拖动，拖动释放在有效选项上只提交最终选项并保留面板；点击/无障碍确认保持选择后关闭。边缘自动滚动同样计为拖动，滑出可见区域或手势取消不提交。

本轮本地 Kotlin 编译及 42 个相关主机测试通过，包含真实拖动选择后保持打开、再次点击关闭，以及完整进度下两套文字透明度互斥。未操作设备，修改后 GPU 像素效果仍待录屏复核。

## 字号与交互简化、窗口二次动画修复
根据最新反馈，选项文字显式使用 16sp（保留系统字体缩放），移除跟手悬停、跨行滑动选择、自动滚动与对应命中模型。保留正常 verticalScroll、单行按压/键盘焦点的同心圆角反馈，点击选择后关闭；不为静止选中项绘制背景。

复核 MIUIX 0.9.4-rc01 的 RemovePlatformDialogDefaultEffects Android 源码发现，本地弹层仅清除了 FLAG_DIM_BEHIND，遗漏 setWindowAnimations(0)。在自定义收回完成、Dialog 真正销毁时，OEM 可再次播放窗口退出动画，符合用户所述“已经收回后又从上往下播放一次”。改为直接调用 MIUIX 公共清理函数，同时清零 windowAnimations、dimAmount 和 dim flag，确保只有组件持有展开/收回时序。来源副本与菜单文字仍保留互斥透明度。

主机测试更新为拖动不选中、点击可关闭，并增加实际 Dialog 窗口动画属性为零和选项 TextLayoutResult 的 16sp 字号断言。

本轮 Kotlin 编译与 40 个相关主机测试通过，包含窗口 windowAnimations=0、无压暗标志、字号 16sp、拖动不选中与点击关闭。未操作设备，HyperOS 实际退出效果待运行时复核。

## 展开首帧来源文字闪跳修复
原逻辑中 graphicsLayer 直接观察 panelOrigin 就绪状态，而来源偏移在 composition 中提前计算。onGloballyPositioned 写入坐标后，图层可能先变为可见，文字仍使用上一轮的 (0,0) 偏移，形成左上角闪跳。

修订为 BoxWithConstraints 中统一计算菜单位置和来源局部矩形，以同一轮 composition 的 layoutReady 控制显示；窗口原点及菜单尺寸都确定后才启动展开动画。来源副本放入 matchParentSize 覆盖层，不参与面板测量，避免副本出现反向改变面板尺寸与锚点。复用 24dp 材质形状、16sp 选项与普通点击选择，保留平台窗口动画禁用。

新增主机 Compose 前 12 帧位置回归：来源副本的 left/top/right 与原右侧值保持一致，避免初始零坐标被显示。

首帧修订的 Kotlin 编译及 19 个 Dropdown/共享 Dialog 宿主主机测试通过，含前 12 帧来源位置检查。规格、差异、有效行检查通过；未操作设备，实机观感待复核。

## 起止文字闪动修订
去掉跨窗口重建的来源文字副本：Preference 与 Popup 共享一个 Animatable，原设置行的当前值/箭头保持同一节点、同一布局，仅按展开进度改变透明度。窗口原点与尺寸就绪之前进度仍为零，原文字正常显示；收回到零时原文字已完全恢复，Dialog 销毁不再触发文字切换。

面板图层在前 25% 展开进度平滑显现，反向收回时渐隐到完全透明，避免最后留下有底色的小胶囊再突然移除。菜单文字仍在来源文字完全淡出后进入，既有定位、圆角、选项字号、总时长与平台动画禁用保持不变。

回归改为逐帧检查展开及收回期间原文字节点 ID 和窗口边界恒定、弹层不存在来源副本，并验证面板与来源透明度在零进度连续。设备观感仍待复核。

## 深色官方截图对齐
用户截图显示圆角附近有暗色弧痕、字体和行距偏大。复核发现 Popup 外框为 24dp，但复用 Dialog 配方的折射几何为 40dp；新增 Dropdown 专用配方，继承 Dialog 的用户微调，仅统一物理圆角为 24dp，外框/材质/折射共用同一常量。

按截图比例将选项改为 14sp 字号/20sp 行高、48dp 最小行高、12dp 行内横向留白（加外层 8dp 为 20dp），默认最小宽度 192dp；保留系统字体缩放与长文本换行。菜单列撑满面板，勾选标记固定在尾侧。既有单来源文字动画和窗口采样保持不变。验收包含深浅主题、玻璃开关、长标签和字号缩放；主机测试不替代设备着色器像素验收。
