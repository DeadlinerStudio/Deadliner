# 滚轮日期与时间选择器

## 背景

日期与时间入口当前仅调用 Material 日历和时钟弹窗。用户希望基于固定版本 Miuix NumberPicker 实现滚轮，并提供交互方式选择。

## 目标

- 设置「使用滚轮日期与时间选择器」：开启后上下滚动数字选择日期、时间；关闭使用 Material 日历、时钟。默认关闭保持现有行为，修改即时生效并持久化。
- 日期为年/月/日三列；时间为 24 小时/分钟两列。日期与时间步骤使用固定高度容器，单份滚轮内容依次淡出/淡入并轻微位移，避免高级材质表面逐帧重新测量。首帧即显示完整邻近数字。
- 日、月、时、分通过连续时间索引滚动：10.31 → 11.1，12月 → 下一年1月，59分 → 下一小时00分；反向借位也成立。完整日期时间午夜进位日期，纯时间选择在24小时内循环。业务日期下限/上限处停止，不循环到不合法日期。
- 接入起止时间、习惯提醒时间和补签入口；滚轮内容由 Deadliner 定制高级材质 MiuixDialog 承载，复用页面 backdrop 与标准柔光玻璃 recipe；高级材质关闭时保留语义色容器。
- 保留日期下限、补签日期上限和最小时间校验；月长及闰年正确，分钟精度统一。
- 公共 GlobalUtils 调用签名保持兼容，实现抽离到专门模块。

## 非目标

不修改任务/习惯业务模型、调度规则、其他平台或 Miuix 依赖版本。

## 用户场景

开启滚轮后编辑任务：选年月日，再选时分；取消任一步不写入。结束时间不得早于起始时间。提醒仅显示时间滚轮。关闭后恢复原 Material 选择器。

## 验收标准

- 日期边界、闰年、月份变化、最小分钟校验及 UTC 日期转换有单元测试。
- :app:assembleDebug 与相关测试通过。
- 模拟器查看滚轮日期、时间、设置开关和 Material 回退。
- 对话框关闭通知仅在最终确认或取消时发出；日期到时间过渡不产生伪关闭。
- 不同 Activity 的选择请求隔离；Activity 退出时取消请求，不保留回调。

## 风险与约束

Miuix 版本 0.9.4-rc01 的 API 通过本地官方 sources.jar 核对。Material 日期是 UTC 日期编码，应按 UTC 解码后作为本地年月日使用，避免时区错日。
当前原入口保留为兼容代理，不构成破坏性接口变更，不需要额外保护提交。新增文件均小于 1000 行，GlobalUtils 减少代码。

## 滚轮实现修订

固定版本 NumberPicker 首帧依赖 onSizeChanged 才绘制行，且仅回传环绕后的值。新增保留 Apache-2.0 标记的本地适配 DeadlinerNumberPicker，提前初始化行像素高度，并在拖动/惯性经过每个数字时发布选择。手势起点独立于父级回传值，停稳后才重置起点，避免数值回传打断惯性或重复叠加位移；MIUIX 的颜色、字号、衰减、缩放、惯性、吸附与触觉反馈保持原实现。调用层使用连续日期/时间索引提供数字标签，支持多圈进位，避免通过末值推断方向。

滚动中的日期、时间进位立即同步其他列，不等待吸附停止。固定对话框高度与单份内容过渡避免重叠两套滚轮和玻璃逐帧缩放。

## 同屏选择与直接联动修订

拖动手势及惯性动画每帧直接发布跨越中线的数字，移除 snapshotFlow 延迟观察；未改变选择的帧不重复回调。数字字重由 SemiBold 降为 Normal。普通手机在同一弹窗内分为日期、时间两页选择，保留页面过渡；宽屏并排显示（5行数字）。按字号缩放后的可用宽度至少 600dp、高度至少 480dp 且 fontScale <=1.35 时使用宽屏合并布局，其余使用分步。明确按可用宽高与字号缩放选择布局，保持同一高级材质 Dialog、日期边界和分钟精度。
