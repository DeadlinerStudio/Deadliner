# Android UI 优化

## 背景
大容器玻璃边缘采样不足，图标字重与 MIUIX 不一致，简洁模式已过时。

## 目标
修复玻璃边缘模糊，统一 330 字重，旧简洁偏好兼容映射 MIUIX；设置使用 Dropdown 和 MIUIX 转场，关闭预测返回；卡片展开详情并可收回。

## 非目标
不修改 iOS/HarmonyOS，不操作物理设备，不更改任务数据格式。

## 用户场景
从任务卡片进入详情，再返回列表；已有简洁模式用户升级后直接进入现代主页。

## 验收标准
本地编译与相关主机单测通过，所有旧样式键映射 MIUIX；玻璃采样包含主模糊与折射空间，设置路由可恢复。

## 风险与约束
保留现有未提交改动；兼容偏好读取，无破坏性数据迁移。真实视觉效果需后续模拟器验收；禁止主力机操作。

## 实现与验证状态
已实现全部代码范围；本地编译与 350 个主机测试通过。边缘模糊与卡片展开已完成代码修复，尚未进行模拟器视觉验收。
