# MIUIX 弹层材质实验室

## 背景

Deadliner 的 MIUIX Dialog 与 Bottom Sheet 已统一通过应用级包装组件接入高级材质。实验室真机调节已经得到最终参数，需要把选定值固化为产品默认值；同时，沉浸式 Dialog 的自定义柔光玻璃与折射 Shader 会造成偏灰、透明采样伪影和向内扩散光，需要回退为纯高级材质主体加弱高光描边。

## 目标

- 为 MIUIX Dialog 和 Bottom Sheet 分别提供背景不透明度与模糊半径调节。
- 固化 Dialog 65%/80dp、Sheet 70%/80dp，并让“恢复默认”使用这些最终值。
- 沉浸式 Dialog 复用普通高级材质的纹理模糊、色彩控制、噪声与主题容器混色，仅叠加不参与采样的弱高光描边。
- 所有通过 `MiuixDialog`、`AlertDialog` MIUIX 分支和 `MiuixBottomSheet` 展示的弹层共享同一参数源。
- 在实验室页面显示当前数值，并提供真实 Dialog 与 Sheet 预览入口。
- 参数调整完成后持久化，应用内其他页面立即采用新值。

## 非目标

- 本轮不修改 Material 3 Dialog/Sheet。
- 本轮不改变弹层圆角、尺寸、动作布局、动效时长或遮罩透明度。
- 本轮不改变沉浸式 Bottom Sheet 的既有柔光玻璃配方。

## 用户场景

1. 用户进入设置的实验室页面，分别拖动 Dialog 和 Sheet 的背景不透明度、模糊半径。
2. 用户点击预览入口打开真实 MIUIX Dialog 或 Bottom Sheet，观察当前参数下的采样、文字可读性和层级。
3. 用户关闭预览后继续调整，数值在松手时保存并立即影响后续弹层。
4. 用户可恢复本轮提供的实验初始值，再继续调试。

## 验收标准

- 实验室页面包含四个带数值标签的连续拖动条：Dialog 不透明度、Dialog 模糊半径、Sheet 不透明度、Sheet 模糊半径。
- 不透明度范围为 20%–95%，模糊半径范围为 0–150dp；非法或非有限值会回退并钳制。
- 最终产品默认值为 Dialog 65%/80dp、Sheet 70%/80dp。
- 沉浸柔光玻璃与非沉浸纹理模糊分支都使用相同的弹层专属参数。
- 沉浸式 Dialog 主体使用与普通高级材质相同的 `advancedTextureBlur` 顺序和主题 `surfaceContainer` 混色；不再串接自定义折射 Shader，只保留 0.5dp 弱渐变高光描边。
- 高级材质关闭或没有可采样 Backdrop 时保持可读的不透明回退，不用透明容器牺牲可读性。
- Dialog 与 Sheet 预览使用生产包装组件，不另造仅供预览的材质实现。
- 设置保存后重启仍可恢复；旧版本没有这些字段时使用新的实验初始值。
- 新增参数规范化、持久化与材质解析测试；Debug 编译和相关单元测试通过。

## 风险与约束

- Blur 是运行时着色器效果，编译和 Compose 预览不能证明真机视觉结果；最终值必须由支持高级材质的设备确认。
- 大半径模糊会在 Miuix 内部降采样；Dialog 禁止在标准高级材质后继续串接会重新采样内容的自定义 Shader，避免透明边界与向内扩散光。
- 调节项仅影响 MIUIX 弹层，不应改变顶栏、导航栏和普通柔光按钮的现有配方。
- Backdrop 仍由页面内容层录制，弹层仅消费，禁止扩大录制祖先范围以免重现 HWUI RenderNode 自引用崩溃。
- 当前工作区包含其他尚未提交改动，本轮只增量修改弹层材质、实验室 UI、字符串、测试和本规格。


## 实现结果

- 高级材质细调模型中的最终默认值已固化为 Dialog 65%/80dp 与 Sheet 70%/80dp；默认版本迁移只替换旧默认值，保留用户自定义值。
- `rememberMiuixModalSurface` 成为统一解析入口：有 Backdrop 时把参数应用到沉浸柔光玻璃或普通 Miuix 纹理模糊，没有 Backdrop 或高级材质关闭时保持不透明 Surface 回退。
- 沉浸式 Dialog 最终回退为 MIUIX 标准 `advancedTextureBlur` 高级材质基底，再叠加 0.5dp 弱渐变高光描边；完全移除 Dialog 的折射、色散和二次模糊 Shader。沉浸式 Sheet 保持原配方。
- Dialog 不再依赖 Miuix 降采样后的 Shader 坐标换算，从链路上消除左下角透明采样区与向内扩散光；Sheet 链路不受影响。
- 实验室新增四个拖动条、当前值、恢复初始值、真实 Dialog 与 Sheet 预览；预览内部也可以实时拖动对应参数，松手后写入全局外观偏好。
- 全量 181 项 Debug 单元测试、Debug APK、Release/R8、`lintVitalRelease`、规格/XML/差异检查通过；ADB 无在线设备，真机视觉确认待完成。
