# Lifi AI 页面重构 · HTML 原型

## 背景
Android 使用共享 AIOverlay，现有未提交改动已包含跨页面保留的运行状态，以及读取任务/习惯、创建任务/习惯的工具审批。先设计原型，不修改应用业务代码。

## 目标
- 参考 iOS 的问候、三个快捷意图、记忆管理和结果卡片；参考鸿蒙的对话历史、宽屏侧栏及工具审批。
- 首页突出自然语言输入，减少大块装饰和重复信息。
- 对话区呈现可折叠处理过程、审批范围、可编辑结果、拒绝/停止/失败恢复。
- 输入区与现代导航分层；切换页面不丢失运行状态。
- 提供浅色/深色、手机/宽屏与可点击的代表状态。

## 非目标
- 不改 Kotlin/Swift/ArkTS，不调用真实模型，不读写真实任务或用户记忆，不部署网站。
- 历史与记忆是跨端对齐提案，原型支持浏览器本次会话内操作，不代表 Android 已接入持久化。
- HTML 模糊仅表达材质意图，原生实现需复用项目 SoftGlassSurface 等组件。

## 用户场景
输入“帮我整理这周的任务”：处理 → 读取审批 → 允许一次 → 结果与建议；用户可拒绝、停止，或离开页面后返回。任务/习惯创建展示具体内容、编辑及一次确认。历史记录只读，当前会话继续独立运行。

## 验收标准
- 本地直接打开 index.html 或静态服务可运行，无外部依赖。
- 快捷建议填入输入框，由用户发送；空输入不能发送。
- 审批卡可允许或拒绝，已处理卡不能重复执行。
- 创建结果可编辑并添加，添加状态明确；运行可停止，失败可重试。
- 新对话归档现有对话；运行中禁止重置；历史可查看和删除。
- 记忆可查看和删除；浅深主题、窄屏/宽屏无内容遮挡。

## 风险与约束
示例数据与运行均为模拟；原型不承诺自动审批、语音、附件或新模型能力。保留现有工作区修改。原型文件按 HTML/CSS/状态脚本拆分，每文件小于 1000 行，不进行原生编译。

## 设计参考
- iOS：`Deadliner/Features/Main/Components/AIFunctionView.swift`、`AIFunctionRendering.swift`。
- 鸿蒙：`entry/src/main/ets/pages/routes/ai/AIPage.ets`、`pages/common/AIPanelView.ets`。
- Android：`ui/agent/AIOverlay.kt`、`AIOverlayPresentation.kt`、`AIAgentSessionState.kt`。
- 标识使用 Android `ic_lifi.xml` 同源路径；不引入其他品牌图标。

## 实现结果
原型包含六个预设状态、任务/习惯编辑、读取范围审批、可折叠执行摘要、安排与拆解结果、后台继续处理、失败重试、只读历史及记忆管理。浅深主题与手机/宽屏共用同一会话状态。可直接打开的 `lifi-ai.html` 为自动导出产物，全部示例在内存中运行。

## 评审调整：柔光玻璃与弱化描边
- 输入框使用半透明磨砂、底部共享柔光和轻微内高光；聚焦只增强柔光，不出现紫色描边。
- 快捷、审批、结果、处理过程、记忆与次级操作去除常规轮廓线，以底色、留白和轻阴影分层；列表内分隔线同步移除。
- 深色与不支持 backdrop-filter 的浏览器保留可读的填充回退。

## Android 原生实施（已获确认）
新建 ui/lifi 页面及组件，现代导航接入 LifiAIPage；不使用 AIOverlay、AIAgentPage 或旧 UI 状态。保留简化模式旧入口。业务继续通过 AIUtils/KMP，审批结果按真实回执展示。任务与习惯创建参数可编辑；读操作展示单次授权范围，拒绝/停止/过期不执行。对话在进程内跨页面持续运行，历史存数据库会话空间；历史只读，不恢复过期授权。记忆使用真实仓库，删除后刷新。输入采用 canonical SoftGlassSurface/quickAdd 配方和独立内容 backdrop；卡片无描边。

原生验收：编译成功；会话新建/历史浏览/停止和重试状态正确；写工具只执行一次，修改参数完整保留；工具失败不能呈现成功。浅深色和宽窄布局由主题与尺寸驱动；运行中新建禁用；IME 不叠加主导航预留。

## 导航补充
Lifi 页隐藏底部导航旁的新增按钮。Tab 始终保留现有宽度上限（竖排 80dp、横排 104dp），恢复按钮占位收拢与 Tab 宽度展开动画，胶囊在每一帧都受现有上限约束并自然居中。隐藏按钮立即禁用并清除语义，收拢结束后不渲染。

## 最新 UI 调整
- Lifi 使用项目共享 Scaffold，顶部不设置大标题，保留历史/新对话操作；记忆与偏好使用有不透明背景的独立 Scaffold 内容页，不再放在透明玻璃弹窗。
- 非输入卡片统一使用主题 SurfaceContainer，无描边。
- 工具请求默认同意，自动执行任务/习惯建议，不再展示审批/编辑操作卡。成功创建显示静态结果，失败和部分完成保留真实回执提示；历史不重放任何操作。
- 输入只统一快速添加容器的 28dp 圆角、柔光材质与阴影，以及实际距导航控件的间距。内容遵循设计稿：无额外标题，独立 Lifi 提示与文案，右下角为单图标发送/停止按钮。Scaffold 背景覆盖状态栏，状态栏 inset 只施加在顶部操作行。
- 遵照用户已有要求，不编译、不运行设备测试。

## 最新承载与分层约束
- 玻璃容器内禁止再次叠加玻璃；输入发送/停止采用无玻璃图标按钮；顶栏 Action 的滚动柔光行为按下方最新要求执行。
- 顶栏叠加在全尺寸内容上，使用共享渐进顶栏材质；列表只用 contentPadding 避让首屏，滚动内容可延伸到顶栏和状态栏下。
- 记忆与偏好改为共享 MiuixBottomSheet 承载；SurfaceContainer 内容卡片保持清晰，读写逻辑不变，关闭后保留当前对话。

## 首页轮播 / 历史 Sheet / 滚动 Action
- 输入发送/停止与快速添加圆形主操作统一：40dp 按钮、20dp 图标，输入容器内不再增加玻璃层。
- 首页三张推荐卡改为横向分页轮播，一次显示一张并提供可点击分页指示，减少被底部输入区域遮挡的内容高度。
- 会话历史改用共享 MiuixBottomSheet 承载，保留当前对话、历史只读浏览与删除，顶栏历史图标采用原型的回转时钟轮廓。
- 按最新要求，顶栏 Action 使用其他页面的 TopBarIconButton，随实际列表滚动渐显柔光玻璃；输入框内部仍禁止玻璃叠玻璃。

## 字体图标 / 底部完整避让 / 自动轮播修正
- 历史入口改为内嵌 Material Symbols Rounded 字体的 history，更新图标映射并通过生成器注册，不再使用独立 vector。
- 推荐卡使用注册的 task_alt、routine、lightbulb 与 chevron_right 字体图标，不再使用 Unicode 字符模拟图标。
- 聊天列表底部 contentPadding 明确累加实测输入栈高度、导航/IME 预留与内容间隔，避免尺寸回调位置导致导航预留漏算。
- 推荐卡每 4.5 秒自动切换，保持滑动和分页点操作；拖动、打开 Sheet、编辑输入及应用进入后台时暂停，交互结束后重新计时。

右上角新建对话操作使用内嵌 Material Symbols Rounded 的 maps_ugc 字体图标，并通过项目图标生成器注册。
