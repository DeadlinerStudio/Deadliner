# MIUIX 官方玻璃实验

## 背景
官方 PR #423 引入 OS4 玻璃材质，当前 Deadliner 自研光学层需要进行并行对比。

## 目标
增加默认关闭、持久化、即时生效的官方玻璃实验开关；材质实现固定到 PR 提交 ec4c96963abf206ab2f2b0253a5efca71ba28043，保留现有页面布局、交互、配色和一键回退。

## 非目标
不替换整个导航或弹层系统，不删除自研后端，不跟随未固定的 PR 头部，不操作物理设备。

## 用户场景
在高级材质设置中开启实验，再查看 Sheet、快速添加、Lifi 输入框、导航/图标按钮，并随时切回原材质。

## 验收标准
开关默认为关闭，重启后保持；受支持表面采用真实官方实现，无 backdrop 或关闭材质时保留可读降级；编译和主机测试通过；明确记录无法覆盖的部分。

## 风险与约束
未合并 PR，接口可能变化；固定源码与出处，保留许可证；现有未提交改动不得覆盖；不进行破坏性数据迁移。

## 当前状态
已实现默认关闭实验选项及材质后端切换，本地编译与 351 个主机测试通过。覆盖主要材质入口；完整官方组件迁移、GPU 性能和实际画面仍需后续评估。

## 实验入口隐藏
根据用户实际观感反馈，隐藏官方玻璃实验开关。旧版开启偏好统一按关闭处理，后续偏好写入清除旧键；保留现有柔光玻璃及全部调参。官方源码和适配仍保留用于日后评估。
