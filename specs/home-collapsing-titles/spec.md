# 主页统一折叠标题

## 背景

主页清单已经使用 MIUIX 的大标题随列表滚动折叠为小标题；概览与收集页仍使用固定的小标题，一级页面的层级与滚动反馈不一致。

## 目标

- 让主页的概览和收集页与清单页一致：进入时显示大标题，内容向上滚动时自然折叠为小标题。
- 保留概览分页、收集页多选和现有顶栏操作。
- 将同一行为同步到独立打开的概览与收集页面。

## 非目标

- 不改变页面的业务数据、筛选、多选、搜索或导航结构。
- 不重新设计列表内容、卡片或配色。

## 用户场景

用户从主页切换到“概览”或“收集”，先看到清晰的大标题；浏览统计或收集条目时标题折叠，保留操作按钮与可读的小标题。

## 验收标准

- 概览和收集页的普通状态使用 `TopAppBarStyle.LARGE` 与 MIUIX `MiuixScrollBehavior`。
- 页面滚动容器连接同一 `nestedScrollConnection`，标题可平滑折叠。
- 多选状态保持紧凑操作顶栏，不使用大标题。
- 独立 `OverviewScreen` 与 `CaptureScreen` 使用相同的折叠策略。

## 风险与约束

- 不创建额外主题或 Scaffold；沿用现有主页 Scaffold 和根 `MiuixTheme`。
- 只修改 Android Compose 视图层，并在统一改动后编译验证。
