# 设置行视觉对齐

## 背景
Dropdown 原先使用 MIUIX 标准 16dp 内边距，自定义设置行多为 24dp；云同步条件缺少其他页惯用的说明式开关样式。

## 目标
所有通用设置行（开关、详情开关、按钮、滑块、单选、信息和图标选择）的左右边距以 Dropdown 为准。清除 SettingItem 调用处额外的 8dp 缩进。云同步条件复用 SettingsDetailSwitchItem，保留说明和既有回调；BYOS/WebDAV 入口移除图标。

## 非目标
不改变设置值、同步后端与手势逻辑；不调整页面外边距、控件尺寸和 Dropdown 动画。

## 用户场景
同一设置卡片中的文字和尾部控件沿统一边线排列，云同步条件与其他设置页一致。

## 验收标准
以 SettingsItemDefaults.HorizontalPadding = 20dp 统一水平内边距，Dropdown 显式采用同一值，保留 MIUIX 原垂直边距；主机几何检查比较 Dropdown 和设置行内容边界，现有云同步控件回归通过。

## 风险与约束
保留点击范围、RTL 与文本布局，核心文件少于 1000 有效行；不操作设备。

## 验证结果
编译及全部 426 个主机测试通过。新增布局回归对比 Dropdown 与导航、普通/详情开关、两种详情按钮、按钮、滑块和两种单选行的文字边界，并核对尾部内容边界，LTR/RTL 均通过。云同步条件和时间下拉操作/持久化测试通过；未操作设备。

## 20dp 更新
通用设置行与 Dropdown 的水平内容内边距统一为 20dp；高级参数、说明及其他自定义设置行一并引用同一常量。页面外边距、Dropdown 弹出菜单几何、图标大小和控件间距保持原样。LTR/RTL 布局测试新增绝对 20dp 断言。

## 主页与子页导航例外
设置主页的 SettingItem 单独使用 16dp 水平内容内边距，二级及更深页面保持 20dp。所有进入应用次级页面的设置行显示统一右箭头；普通操作、开关、Dropdown 不额外显示导航箭头。外观/行为入口恢复默认箭头；关于页更新/捐赠/许可/政策和小组件编辑明确标记为导航，保留其语义图标。
