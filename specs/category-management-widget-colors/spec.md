# Android 分类管理与小组件分类色

## 背景

Android 已能给任务选择分类并按分类筛选，但主应用缺少分类的新建与编辑入口。2x1/2x2 Glance 小组件的任务竖线目前只表达任务的时间状态，没有利用任务分类颜色。

## 目标

- 在主应用提供统一的分类管理页面，支持新增分类和编辑现有分类的名称、图标与颜色。
- 在分类编辑页提供带确认提示的软删除；删除后保留任务与习惯，仅将悬空分类按“未分类”呈现。
- 分类写入复用 KMP `CategoryMutation` 与 `CategoryRepository`，保留跨端校验、同步变更日志与仓储更新通知。
- 从现有分类选择与分类筛选界面进入分类管理；返回原页面后可立即使用最新分类。
- 为分类列表/编辑页面切换和分类 Sheet 收起补齐过渡动画。
- 修正主页筛选中“未分类”的深浅色适配，去掉分类徽标外的重复名称，并提高管理页徽标文字可读性。
- 统一分类 Sheet 与管理页的标签圆角、字号、图标和内边距；管理页只保留列表内的新增入口。
- 简化新增/编辑分类表单：名称输入框不再包裹设置 Section，顶栏和底栏复用编辑器高级材质链路。
- 分类编辑页必须与任务编辑页使用同一透明 Backdrop 页面壳；顶栏动作（含删除）在沉浸模式下使用柔光玻璃容器。
- 透明页面壳的 `LayerBackdrop` 录制阶段必须先绘制当前主题的不透明 Surface，再绘制页面内容，避免顶栏、底栏与柔光按钮只得到透明染色而没有有效背景采样。
- 分类管理与编辑复用设置页同款 Activity 根宿主：页面级模糊宿主和不透明 Surface 位于 `NavHost` 动画之外，列表与编辑作为同一导航栈中的页面切换。
- 分类管理与编辑各自通过页面 Scaffold 的内容 Box 录制 `LayerBackdrop`；顶栏、底栏、柔光按钮和弹窗只作为该内容录制层的兄弟消费者，不得把消费者包入同一录制祖先。
- 分类编辑短表单必须提供至少一个顶栏高度的额外尾部滚动空间，使表单内容能够实际移动到顶栏及其柔光按钮下方并被 Backdrop 采样。
- “全部分类”每一项提供独立删除动作，无需进入编辑页；列表与编辑页复用同一 MIUIX 删除确认弹窗和同一软删除编排。
- 主页任务卡片使用独立的紧凑分类标签字号，不反向缩小 Sheet、管理页或习惯卡片标签。
- 主页任务卡片紧凑标签的整体高度不得高于备注文字行高，避免分类存在与否改变卡片第二行高度。
- 2x1 和 2x2 Glance 小组件读取任务分类：有效分类存在时竖线使用分类颜色，否则继续使用任务卡片当前的时间状态语义色。
- 分类保存后主动请求 Android 小组件刷新。

## 非目标

- 本轮不增加分类恢复、拖拽排序或批量管理。
- 本轮不修改 iOS、HarmonyOS 的分类管理页面。
- 本轮不改变任务临期、逾期判断和任务排序规则。

## 用户场景

1. 用户在首页分类筛选或任务编辑的分类选择页点击“管理分类”，进入分类管理页。
2. 用户点击“新增分类”，填写名称并选择图标、颜色，保存后回到分类列表且新分类立即可见。
3. 用户点击已有分类进行编辑，保存后任务列表、分类选择器与小组件使用新名称、图标和颜色。
4. 小组件任务有分类时用分类色竖线；无分类、分类缺失或分类已删除时仍用卡片语义色。
5. 用户从分类编辑页删除分类，确认后平滑返回列表；原分类下的任务与习惯保留并按“未分类”处理。
6. 用户在添加任务时选中分类，Sheet 播放完整退出动画后再从组合树移除。

## 验收标准

- 新建空名称不能保存，并显示可理解的校验提示。
- 新建分类使用稳定唯一 UID，排序位于当前有效分类之后。
- 编辑分类保留 UID、预设标记、排序和创建时间，只更新允许编辑的字段与更新时间。
- 删除分类调用 KMP 仓储软删除并保留同步变更日志；删除失败时不退出编辑页。
- 分类颜色使用 KMP 支持的 `#RRGGBB` 值；图标只提交 KMP 支持的语义 ID。
- 主应用所有现有分类选择/筛选入口均能打开同一管理页面。
- 从管理页面返回后，仍在前台的任务编辑页和首页能重新加载分类。
- 两种 Glance 小组件均能呈现分类色竖线，且无分类回退行为有单元测试。
- Android 单元测试、Debug 编译、Release/R8 与 release lint 通过；产物使用正式证书签名并校验证书摘要。
- 分类管理页与编辑页切换有方向一致的滑动/淡入淡出动画；分类选择 Sheet 在选择后完成退出动画。
- “未分类”图标及文字使用当前 Miuix 语义色；带名称的半透明徽标不再在外部重复显示名称。
- “全部分类”中的徽标使用可读的正文级文字与更大的图标/内边距。
- 分类管理页顶栏不显示重复的新增按钮，列表底部“新增分类”入口仍可用。
- 分类 Sheet 与管理页使用同一个标签 Composable，圆角和字体完全一致，字体比上一版略小。
- 分类名称输入框直接位于滚动内容中，不显示外层 Section 卡片和重复标题。
- 启用高级材质/沉浸体验时，分类编辑页滚动会驱动渐进顶栏材质，固定底栏采样同一页面 Backdrop；关闭高级材质时仍有可读的实色回退。
- 分类编辑页的页面壳、顶栏 Backdrop 与底栏 Backdrop 行为和添加任务页一致；删除按钮通过顶栏柔光玻璃动作组件承载，保留按钮语义和可点击目标。
- 内容滚动到顶栏或底栏下方时，渐进顶栏、固定底栏和柔光按钮必须共享一个包含主题底色与页面内容的有效 Backdrop；透明 Scaffold 不得导致采样层透明。
- 分类编辑页的 Backdrop、顶栏、底栏和删除弹窗必须位于设置页同款的稳定根宿主下；页面级模糊宿主与不透明 Surface 不得被列表到编辑页的导航变换图层包裹。
- 列表项删除按钮具有独立点击目标和删除语义，不触发编辑；确认后列表、小组件立即刷新，失败则保留分类并显示失败提示。
- 删除确认在 MIUIX 模式下使用项目统一的 `MiuixDialog` 标题/摘要结构，以及与设置页一致的等宽填充动作按钮尺寸；Material 3 模式仍保持原生 AlertDialog 行为。
- 删除确认按钮使用危险操作语义色：容器为 `errorContainer`、文字为 `onErrorContainer`，不得出现蓝色主按钮容器搭配红色文字。
- 主页任务卡片分类标签使用紧凑排版，文字显著小于 Sheet/管理页标签；其他分类标签默认规格不变。
- 主页任务卡片紧凑标签使用不大于备注的文字规格，并移除额外垂直内边距；有无分类时备注行的排版高度保持一致。

## 风险与约束

- 当前工作区包含上一轮尚未提交的小组件改动；本轮只增量修改相关文件，不回退用户已有改动。
- Glance 不能直接使用 Compose `Color`，分类颜色需转换为 ARGB 后通过 `ColorProvider` 渲染。
- 页面遵循当前应用 MIUIX 主题、页面壳与固定底部操作区，不在局部重新创建主题根。
- 无真机在线时，编译与静态测试不能替代 MIUI/桌面启动器上的最终视觉验证。

## 实现结果

- Android 新增独立分类管理 Activity；列表页可新建或进入编辑，编辑页以固定底部保存操作承载名称、36 个语义图标及跨端 20 色加 MIUIX 蓝的选择。
- 新建分类默认使用 MIUIX 蓝 `#3481FF`；创建与更新均调用 KMP `CategoryMutation` 和 `CategoryRepository`，预设分类的身份、排序与创建元数据保持不变。
- 首页两种布局、任务/习惯编辑器和任务详情的分类目录改为生命周期可重载状态，并从原有分类选择/筛选面板统一进入管理页。
- Glance 数据源只解析有效分类；2x1 与 2x2 共用任务项模型，有分类时竖线使用分类 ARGB，无分类、悬空或已删除分类时回退到临期/逾期等卡片语义色。
- 分类仓储通知与保存后的显式刷新共同请求小组件更新。
- 161 个 Debug 单元测试零失败；Debug、Release/R8、`lintVitalRelease`、规格校验与差异检查通过。新增核心文件最大 197 行，无超过 1000 行文件。
- 上一轮交付时 ADB 无连接设备，MIUI 真机视觉和交互验证当时未执行。
- 分类编辑页现已通过 KMP `CategoryRepository.softDelete` 支持带确认提示的软删除；任务与习惯记录不被删除，现有分类 resolver 将悬空引用继续按“未分类”处理。
- 管理列表与编辑页使用方向一致的水平滑动加淡入淡出过渡；分类选择/筛选 Sheet 在收到关闭请求后保留在组合树中，等待 Miuix `onDismissFinished` 再通知调用页移除。
- 分类 Sheet 中带文字的半透明徽标不再重复渲染外部名称；“未分类”图标显式使用当前 Miuix `primary/onSurface` 语义色；Sheet 与管理页统一使用 12dp 圆角、正文级小号文字、16dp 图标和一致内边距的 `CategoryBadge`。
- 首页在分类目录变化时会清理已经删除的筛选 UID，避免删除当前筛选分类后主页保持空白。
- 2026-09-03：12 个分类单元测试零失败，Debug Kotlin 编译与 Debug APK 组装通过，规格校验通过；连接设备已成功安装 Debug 包，但设备处于安全锁屏，未完成页面动画与深浅色的真机视觉确认。
- 分类管理页已移除顶栏重复新增按钮，仅保留列表底部入口；分类名称输入框已从 Section 卡片中移出。分类编辑页改用带内层栏位留白的 LazyColumn，滚动状态驱动渐进顶栏，内容同时为顶栏与固定底栏提供共享 Backdrop；关闭高级材质时沿用页面壳的实色回退。
- 分类编辑页进一步改为与添加任务页完全相同的透明 `AdaptiveMaterialScaffold` Backdrop 宿主；删除动作改用 `TopBarIconButton`，因此在 Miuix 沉浸体验中随顶栏材质进度显示柔光玻璃。主页任务卡片单独使用 `footnote1`/`labelSmall` 与 12dp 图标的紧凑分类标签，不改变 Sheet、管理页和习惯卡片的默认标签规格。
- 透明页面壳的 Backdrop 录制回调现会先填充当前 Material/Miuix Surface，再录制实际页面内容，修复顶栏、底栏与柔光按钮只有半透明染色、缺少有效背景采样的问题；主页紧凑标签同时取消垂直内边距并统一使用 `labelSmall`。
- 分类管理与编辑改为复用设置页同款根层级：`DeadlinerTheme → 页面级模糊宿主 → 不透明 Surface → NavHost → 页面 Scaffold`。列表与编辑保留同 Activity 导航过渡，Backdrop 根宿主不参与页面变换。
- “全部分类”每一项现有独立删除按钮，列表与编辑页共用归档页风格的 MIUIX 删除确认组件；确认后执行同一软删除逻辑并刷新列表与小组件。
- 分类页面的 Backdrop 继续由 `AdaptiveMaterialScaffold` 内容层录制，并通过页面级 MIUIX 模糊宿主注册给兄弟弹窗；录制节点不再包裹任何使用同一 Backdrop 的组件。
- 分类删除确认按钮已撤回较小的 Miuix 文字按钮分支，改为与设置页弹窗相同的等宽填充动作按钮。
- 2026-09-03 真机日志确认，把根 `NavHost`（含顶栏等 Backdrop 消费者）整体挂到同一 `layerBackdrop` 会在 Android HWUI 形成 RenderNode 自引用并触发 RenderThread 原生栈溢出；该不安全实现已撤回。
- 分类编辑短表单现额外提供一个顶栏高度的尾部滚动空间，使输入框、颜色和图标内容能够越过顶栏采样区；继续使用内容层录制与兄弟消费结构，不扩大 Backdrop 祖先范围。
- 分类删除确认保留 MIUIX 等宽填充动作按钮尺寸，同时允许危险操作覆盖默认主按钮配色，确认按钮现使用 `errorContainer/onErrorContainer`。
