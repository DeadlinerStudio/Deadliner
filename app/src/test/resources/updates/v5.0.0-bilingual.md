## 📌 更新日志 / Changelog

#### 🌏 **中文**

### v5.0.0

* **🎨 全新界面与设计系统**：
    * 全面刷新 Deadliner 的现代化界面，基于 miuix-compose 组件库重新设计主页面、任务编辑、任务详情、概览、归档、设置和关于页面。aka Issue #25
    * 新增 **简洁模式** 与全新的 **现代模式**，带来更聚焦或更完整的两种使用体验。
    * 引入自适应页面布局、导航栏与顶部栏，在不同屏幕尺寸下提供更协调的显示效果。

* **🌈 更丰富的个性化设置**：
    * 新增 **现代 / 鲜明** 两种设计模式，以及多种 Material 3 动态配色生成策略。
    * 新增 **高级材质效果**，可选择通透、轻盈、柔和、朦胧和深邃等不同模糊层级。
    * 新增显示大小预设和自定义缩放比例。
    * 新增默认、自动四季以及春、夏、秋、冬应用图标。
    * 提供 HyperOS、HONOR、OPPO 和 vivo 等现代界面中性色风格。

* **🔍 搜索、归档与灵感管理升级**：
    * 新增统一搜索页面，可搜索灵感、当前任务、习惯及归档内容。
    * 全面重构归档页面，支持搜索、恢复和永久删除任务或习惯。
    * 新增灵感页面，支持批量选择、删除，以及将多条灵感合并整理为任务或习惯。

* **📊 全新概览与数据洞察**：
    * 重构概览页面，新增待办、累计完成、累计放弃和累计逾期等统计指标。
    * 新增贡献热力图、活动分布、周度逾期数据和更多趋势图表。
    * 新增 **AI 月度洞察**，帮助回顾上月任务表现与活动规律。

* **🤖 Lifi AI 体验升级**：
    * 新增统一的 **BYOK** 配置流程，支持自定义 API Key、Base URL 和模型 ID，并可在保存时验证配置。
    * 新增自动批准只读请求、静默创建任务和隐藏思考过程等交互选项。
    * 可独立关闭 AI 功能并隐藏相关入口。

* **✨ 引导与细节优化**：
    * 重新设计首次启动与功能引导流程，帮助快速完成配色、材质和主界面选择。
    * 优化任务剩余时间展示、提醒调度、实时活动和多项交互细节。
    * 经典模式进入 Legacy 阶段：现有用户仍可继续使用；切换到其他模式后，经典模式入口将不再显示。Issue #27 在新 UI 中不再出现问题。

#### 🌍 **English**

### v5.0.0

* **🎨 A Completely Refreshed UI and Design System**:
    * Completely redesigned Deadliner’s modern interface with the miuix-compose component library, covering the home screen, task editor, task details, Overview, Archive, Settings, and About pages. See #25.
    * Added a focused **Simplified Mode** and a new, feature-rich **Modern Mode**.
    * Introduced adaptive layouts, navigation surfaces, and top app bars for a more consistent experience across screen sizes.

* **🌈 More Ways to Personalize Deadliner**:
    * Added **Modern** and **Vivid** design modes with multiple Material 3 dynamic color-generation styles.
    * Added Advanced Material with Crystal Clear, Light, Soft, Hazy, and Deep blur levels.
    * Added display-size presets and custom scaling.
    * Added default, automatic seasonal, spring, summer, autumn, and winter app icons.
    * Added HyperOS, HONOR, OPPO, and vivo-inspired neutral surface palettes for Modern Mode.

* **🔍 Better Search, Archive, and Inspiration Management**:
    * Added unified search across inspirations, active tasks, habits, and archived items.
    * Rebuilt the archive experience with search, restore, and permanent deletion controls.
    * Improved Inspiration with batch selection, deletion, and merging multiple ideas into a task or habit.

* **📊 A New Overview and Deeper Insights**:
    * Redesigned Overview with pending, completed, abandoned, and overdue metrics.
    * Added a contribution heatmap, activity distribution, weekly overdue data, and improved trend charts.
    * Added **AI Monthly Insights** to summarize last month’s task performance and activity patterns.

* **🤖 Upgraded Lifi AI Experience**:
    * Added a unified **BYOK** setup for custom API keys, Base URLs, and model IDs, including online validation.
    * Added options to auto-approve read-only requests, silently create tasks, and hide intermediate thinking states.
    * AI features and entry points can now be disabled independently.

* **✨ Onboarding and Detail Improvements**:
    * Redesigned onboarding and feature guidance for choosing colors, materials, and the preferred home-screen style.
    * Improved remaining-time labels, reminder scheduling, live updates, and many interaction details.
    * Classic Mode has entered the Legacy stage: existing users can continue using it, but its entry will no longer appear after switching to another mode. The issue described in #27 no longer occurs in the new UI.
