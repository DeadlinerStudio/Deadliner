# 外观设置重构方案 v2

## 概览
- `界面外观` 继续作为主设置中的一个二级页，不提升为主设置一级分类。
- 外观页内部改为四段结构：
  - `Section(设计)`：`设计与色彩`、`高级材质`
  - `Section()`：`应用图标`
  - `Section(界面外观)`：`主界面风格`、`显示大小`
  - `Section()`：4 个原有外观开关
- `显示大小` 保留在外观页中，不单独移到设置首页。

## 页面结构
- `AppearanceSettingsScreen`
  - 顶部新增提示卡片“试试这些新功能”
  - 首次进入显示轻量欢迎 overlay
  - 分组入口调整为：
    - `设计与色彩`
    - `高级材质`
    - `应用图标`
    - `主界面风格`
    - `显示大小`
  - 原有 4 个开关保留在主页：
    - `主界面进度方向`
    - `激励文案`
    - `完成烟花`
    - `详情展示模式`

## 子页行为
- `设计与色彩`
  - 顶部为可实时刷新的 Compose 预览 banner
  - 设计模式只暴露两种用户文案：
    - `现代`：内部映射 `MIUIX`
    - `鲜明`：内部映射 `Material3`
  - `现代` 模式配置：
    - `强调色`
    - `去线留白`
    - `背景色策略`，正式承接原实验室里的 `HyperOS / HONOR / OPPO / vivo` 中性色表面方案
    - `多彩任务指示标`
  - `鲜明` 模式配置：
    - `强调色`
    - `去线留白`
    - `颜色生成策略：Material3颜色`
    - `多彩任务指示标`
- `高级材质`
  - 顶部 banner 使用背景图 + 模糊圆角容器预览
  - 先放总开关，再放“模糊大小”单选组
  - 档位映射：
    - `通透`：28 / 1.05
    - `轻盈`：60 / 1.02
    - `柔和`：128 / 1.00
    - `朦胧`：196 / 0.98
    - `深邃`：256 / 0.95

## 状态与兼容
- `AppearancePreferences` 新增：
  - `designMode`
  - `advancedMaterialLevel`
  - `modernHideDivider`
  - `vividHideDivider`
- 兼容旧字段：
  - `theme_style / miuix_mode` 迁移为 `designMode`
  - `advanced_material` 迁移为高级材质总开关
  - `hide_divider` 若存在，则同时迁移给 `modernHideDivider / vividHideDivider`
- `GlobalUtils.hideDivider` 改为读取当前设计模式下的有效值，确保旧调用点不需要逐个重写。

## 色彩策略
- `现代` 模式的 `背景色策略` 正式承接原实验室里的品牌化中性色表面方案：
  - `HyperOS`
  - `HONOR`
  - `OPPO`
  - `vivo`
- 当用户没有历史选择时，默认值仍可由设备品牌解析得出；一旦手动选择，后续持久化使用用户选择。
- `颜色生成策略（Material3颜色）` 只做说明展示，继续沿用现有动态色 / 种子色生成链路。

## 实验室收口
- 从 `LabSettings` 下线正式外观入口中的旧实验项：
  - `MIUIX 主题模式`
  - `现代色彩方案手动选择`
- 保留实验室中的 `自定义显示大小` 和其他非外观实验项。

## 验证重点
- 外观页 section 顺序和入口名称与方案一致
- `设计与色彩 / 高级材质 / 应用图标 / 主界面风格 / 显示大小` 均可正常进入返回
- `去线留白` 按 `现代 / 鲜明` 分别记忆
- `高级材质` 5 档正确映射到 `blurRadius / blurSaturation`
- 首次进入欢迎层只展示一次
